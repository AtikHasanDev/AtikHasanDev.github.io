Creative Studio Marketplace

StudioSpace

A marketplace for discovering, hosting, and reserving creative workspaces by the hour. Creators can compare studios, and hosts can manage their own listings.

Visit live projectView client on GitHub

Technology stack

  • Next.js
  • React
  • TypeScript
  • Tailwind CSS
  • Express.js
  • MongoDB
  • Better Auth

What it does

  • Browse and filter studios by category; review photos, amenities, capacity, host information, and hourly rates.
  • Sign in with email and password or Google. Hosts can publish, edit, and delete their listings with photo uploads.
  • Request time slots, track bookings, cancel pending reservations, and check for overlap with confirmed bookings.

Development challenges

Technical challenges reflected in the project's features and implementation:

  • Coordinating authentication between a Next.js client and a separate Express API using short-lived JWTs and protected requests.
  • Checking requested time intervals against confirmed bookings to prevent overlapping reservations.
  • Keeping listing ownership, image uploads, and booking states consistent across the interface and API.

Potential improvements

Suggested next steps for a future version:

  • Add a host approval dashboard with clearer booking status updates.
  • Add calendar-based availability and more flexible date and location filters.
  • Expand automated coverage for booking conflicts, permissions, and session restoration.
